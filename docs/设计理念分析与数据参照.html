一、总体设计哲学

🎮 核心设计理念：策略自由度最大化

三国自走棋的设计遵循"规则简洁、策略深邃"的原则。每个子系统都力求简单易懂，但组合起来产生丰富的战术深度：

  • 协鸣 × 装备 × 科技：三层加成系统叠加，玩家可以在不同维度做出选择
  • 装备无类型限制：4个自由槽位，玩家完全自主决定搭配策略
  • AI风格差异化：7个对手各有不同策略，避免所有战斗感觉雷同
  • 伤害公式透明：回合+三角数，玩家可以准确预估战斗后果
设计约束：单AI玩家零操作要求（自动战斗），不需要联机配对，适合碎片时间。所有数据硬编码在JS中（无服务器依赖），可离线运行。

二、协鸣系统设计

2.1 双重协鸣架构

每个武将拥有 1个阵营协鸣 + 1个职业协鸣。 这意味着一张卡同时参与两个协鸣池的计算，给阵容构建提供了非线性决策空间。

例如：赵云（蜀+战士）放进4蜀3战士阵容中，同时激活了蜀国4人Tier2和战士2人Tier1，产生协同爆发。

2.4 协鸣叠加机制

协鸣效果之间是乘法叠加，而非加法。例如：蜀国T1（暴击+15%）+ 刺客T1（暴击+25%）= 40%暴击率。 这创造了一种"1+1>2"的协同效应，鼓励玩家探索跨阵营+跨职业的混合阵容。

四、装备系统设计

4.1 自由槽位理念

设计决策：为什么不做类型限制？

传统装备系统通常按槽位类型限制（武器槽/防具槽/坐骑槽），这实际上是在替玩家做选择。自由槽位将全部决策权交还玩家：

  • 玩家A：吕布装备4把武器（方天画戟+青龙刀+穿云弓+绝影）→ 极限输出流
  • 玩家B：吕布装备4件防装（玄武甲+藤甲+黄金铠+护身符）→ 铁壁坦克流
  • 玩家C：吕布2攻2防 → 均衡流

同一张卡，4种完全不同的玩法方向。这种"溢出可能性"带来的策略深度远比固定槽位丰富。

4.3 装备与协鸣的乘法效应

吕布（5费，ATK=100）+ 4件攻击装（方天画戟+30, 青龙刀+15, 绝影+25%攻速, 暴击戒指+15%暴） + 战士协鸣T2（ATK+30%）+ 蜀国协鸣T1（暴击+15%）+ 刺客协鸣T1（暴击+25%） = 基础ATK 100+45=145 × 1.3 = 188.5 → 双协鸣暴击率 10%+15%+15%+25%=65% → 每次攻击期望伤害 = 188.5 × (0.35 + 0.65×1.5) = 188.5 × 1.325 = ~250

从100基础攻击到250期望伤害——2.5倍增幅来自装备和协鸣的乘法叠加。这就是策略深度的来源。

5.2 售卖公式设计

一星售卖 = cost，二星 = 3×cost，三星 = 9×cost。合星消耗3张但售价3倍——打平。如果从商店3次购买同卡，总花费3×cost，合成二星售价3×cost，恰好不亏。这避免了"合星反而贬值"的悖论。

5.3 升级成本曲线

自动vs手动：自动升级是"免费"的，但需要耐心。手动升级立即生效但花费金币。这是时间-金钱的经典权衡——战线拉长时自动更优，需要即时战力时手动更优。

6.2 AI间对战模拟

每轮后台有AI间对战（排除当前与玩家对战的AI）。用的是实力比随机判定而非完整战斗模拟—— 因为完整模拟7场AI对战太消耗性能且玩家不可见。实力比公式：

teamPower = Σ( (ATK + DEF×0.6) × maxHP × (0.5 + SPD) ) 胜率 = powerA / (powerA + powerB) 存活数 = team.length × (胜方实力比 / (1 + 胜方实力比))
为什么不完整模拟？这是典型的"结果近似 vs 过程还原"的设计权衡。完整模拟AI对战需要渲染7组战斗，对性能影响大且对玩家体验无增量价值。实力比模型能快速得出合理结果，满足"背景淘汰"的需求。

七、战斗数值设计

7.1 伤害公式

实际伤害 = max(1, 攻击伤害 - DEF×0.5) × (1 - damageReduction) - shield

护甲减免采用半值公式（每点防御减少0.5伤害），防止防御堆叠导致无敌。减伤是独立的乘法因子（坦克协鸣、技能效果）。

设计意图：三角数使碾压局（对方5人存活→16+伤害）和险胜局（对方1人存活→2伤害）产生巨大伤害差。这个机制天然地惩罚"实力差距过大"的局面，避免强者无限滚雪球——越碾压对方，对方受的伤越重，越早被淘汰。

7.3 暴击模型

基础暴击率10%，暴击伤害1.5倍。蜀国T1+15%、刺客T1+25%、暴击戒指+15%、绝影+10%、科技致命一击+10% → 最大可达85%暴击率。暴击是游戏中最重要的伤害放大器。

7.4 目标选择AI

优先级：有嘲讽→攻击嘲讽者 > 最低血量目标

简单高效的二值选择。嘲讽（坦克T2）可以强制改变对方攻击目标，实现"保护后排"的战术效果。

八、科技系统设计

8.1 科技轮次安排

装备轮：1/2/5/7/10/13/17/21/25 — 共9轮，频率前期高后期低

科技轮：3/4/6/8/9/11/12/14/15/16/18/19/20/22/23/24 — 共16轮，覆盖中后期

设计逻辑：前期快速给装备（1-2轮就有武器），让玩家立刻体验装备系统。中期科技密集出现（3-15轮几乎每轮都有），后期间隔拉长给玩家消化时间。

8.2 科技选择策略

每次从剩余未习得的科技中随机3选1。不能重复获得同一科技。后期池子缩小，更容易获得想要的科技——这创造了一种"越往后越容易出关键科技"的预期。

九、整体平衡性分析

9.1 当前已知平衡点

✅ 协鸣人数门槛合理

2/4/6人分层使小协鸣容易达到但效果弱，大协鸣难达到但效果质变。符合"投入-回报"曲线。

✅ 装备性价比递减

低费装单位金币效率高，高费装提供复合/功能性。玩家根据经济状况做选择。

⚠️ 蜀国偏强

蜀国6将+暴击体系，成型容易且输出爆炸。需观察是否需下调暴击数值。

⚠️ 弓手/坦克池太浅

黄忠独苗弓手，坦克仅许褚+廉颇。后续需扩充武将池。

⚠️ 经济滚雪球

连胜+高利息可能形成不可逆的经济优势。或需引入"连败补偿"机制。

⚠️ 5费卡过强

吕布无双5秒AOE+无敌，后期一张可翻盘。需观察是否需加cd或减伤。

9.2 未来平衡性优化方向

  • 扩充武将池：增加吴国、坦克、弓手、辅助方向的英雄
  • 引入连败补偿：连败额外金币或免费刷新
  • 调优5费卡：稍微拉低吕布/孙策的AOE效率
  • 调优暴击体系：蜀国T1暴击15%→12%可能更合理
  • 引入更多装备：给法系、辅助专属装备
