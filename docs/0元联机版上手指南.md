# 三国自走棋联机版 · 0元上手指南

> 目标：把单机版升级为支持 2-8 人实时对战，**总成本：0 元**  
> 技术栈：Vercel（前端托管）+ Supabase（数据库+实时通信）+ GitHub（代码托管）

---

## 一、为什么是 0 元方案？

| 方案 | 年成本 | 优势 | 劣势 |
|------|--------|------|------|
| 腾讯云 BF1.MEDIUM2 | ¥166.32 | 国内访问快、可挂多项目 | 需要运维、续费麻烦 |
| **Vercel+Supabase** | **0元** | 不运维、全球CDN、自带HTTPS | 国内访问偶尔慢 |
| 阿里云/华为云 | ¥60-300 | 国内快 | 仍需付费 |

**结论**：先用 0 元方案跑通联机逻辑，等真要大规模运营再迁回腾讯云也不迟。

```
                                └────────────────────┘
                                          ▲

                                ┌────────────────────┐

                                │  (前端跑，但带     │
                                │   校验+日志上传)   │
                                └────────────────────┘
```

**关键决策**：
- **战斗逻辑放前端**（确定性回放）：每台客户端用同一份战斗代码，根据相同输入产生相同结果，结束后上传日志对比
- **状态同步用 Supabase Realtime**：玩家操作→写库→推送给房间内所有客户端
- **没有独立服务器**：用浏览器作为"客户端+战斗模拟器"，省掉 Node.js 服务端运维

### 第 3 步：建数据库表（5 分钟）

在 Supabase 控制台 → **SQL Editor** → **New query**，粘贴以下 SQL 一次性执行：

```sql
-- 玩家档案表
create table players (
  id uuid primary key default gen_random_uuid(),
  username text not null unique,
  created_at timestamp default now(),
  mmr int default 1000,
  wins int default 0,
  losses int default 0
);

-- 房间表
create table rooms (
  id uuid primary key default gen_random_uuid(),
  code text unique not null,        -- 6位邀请码
  host_id uuid references players(id),
  status text default 'waiting',    -- waiting / playing / finished
  max_players int default 8,
  current_round int default 0,
  created_at timestamp default now()
);

-- 房间成员表
create table room_members (
  room_id uuid references rooms(id) on delete cascade,
  player_id uuid references players(id),
  board_state jsonb,                -- 棋盘状态
  gold int default 10,
  health int default 100,
  is_alive boolean default true,
  joined_at timestamp default now(),
  primary key (room_id, player_id)
);

-- 战斗日志表
create table battles (
  id uuid primary key default gen_random_uuid(),
  room_id uuid references rooms(id),
  round int,
  attacker_id uuid references players(id),
  defender_id uuid references players(id),
  log jsonb,                       -- 战斗tick日志
  winner text,
  created_at timestamp default now()
);

-- 开启实时订阅
alter publication supabase_realtime add table rooms;
alter publication supabase_realtime add table room_members;
alter publication supabase_realtime add table battles;
```

## 四、改造代码：让 game.js 支持联机

### 4.1 新增 `js/supabase-client.js`

```javascript
// Supabase 客户端封装
const SUPABASE_URL = window.SUPABASE_URL || '你的URL';
const SUPABASE_KEY = window.SUPABASE_ANON_KEY || '你的KEY';
const supabase = window.supabase.createClient(SUPABASE_URL, SUPABASE_KEY);

const Online = {
  // 注册/登录（用本地存储做简化版）
  currentPlayer: null,
  
  async login(username) {
    // 简化版：先查后插
    const { data: existing } = await supabase
      .from('players')
      .select()
      .eq('username', username)
      .single();
    
    if (existing) {
      this.currentPlayer = existing;
      localStorage.setItem('player_id', existing.id);
      return existing;
    }
    
    const { data: created } = await supabase
      .from('players')
      .insert({ username })
      .select()
      .single();
    
    this.currentPlayer = created;
    localStorage.setItem('player_id', created.id);
    return created;
  },
  
  // 生成6位邀请码
  generateRoomCode() {
    return Math.random().toString(36).substring(2, 8).toUpperCase();
  },
  
  // 创建房间
  async createRoom() {
    const code = this.generateRoomCode();
    const { data: room } = await supabase
      .from('rooms')
      .insert({ code, host_id: this.currentPlayer.id })
      .select()
      .single();
    
    await supabase.from('room_members').insert({
      room_id: room.id,
      player_id: this.currentPlayer.id
    });
    
    return room;
  },
  
  // 加入房间
  async joinRoom(code) {
    const { data: room } = await supabase
      .from('rooms')
      .select()
      .eq('code', code)
      .single();
    
    if (!room) throw new Error('房间不存在');
    
    await supabase.from('room_members').insert({
      room_id: room.id,
      player_id: this.currentPlayer.id
    });
    
    return room;
  },
  
  // 订阅房间状态
  subscribeRoom(roomId, onUpdate) {
    return supabase
      .channel(`room-${roomId}`)
      .on('postgres_changes', 
        { event: '*', schema: 'public', table: 'room_members', filter: `room_id=eq.${roomId}` },
        payload => onUpdate(payload)
      )
      .subscribe();
  },
  
  // 上传战斗结果
  async uploadBattle(roomId, round, attackerId, defenderId, log, winner) {
    await supabase.from('battles').insert({
      room_id: roomId, round,
      attacker_id: attackerId, defender_id: defenderId,
      log, winner
    });
  }
};
```

## 六、可能遇到的问题

| 问题 | 解决方案 |
|------|----------|
| Vercel 部署后白屏 | 检查 `index.html` 路径，Vercel 默认找根目录的 `index.html` |
| Supabase 连接报错 | 检查 URL Configuration 里是否添加了 Vercel 域名 |
| 国内访问慢 | 注册 Cloudflare 账号，把域名 CNAME 解析过去加速 |
| 推送代码要密码 | 用 Personal Access Token，不是 GitHub 密码 |
| 实时同步卡顿 | Supabase 免费版有 200ms 延迟，做实时对战够用 |

## 七、什么时候该迁回腾讯云？

| 触发条件 | 迁移动作 |
|----------|----------|
| 同时在线 > 50 人 | 迁回腾讯云 + 独立 WebSocket 服务端 |
| 想挂云表格/ERP | 用腾讯云一台机器多开服务 |
| 国内访问太慢 | 套 Cloudflare 即可，不一定要迁 |
| 数据库超过 500MB | Supabase 升级或迁回腾讯云 MySQL |
